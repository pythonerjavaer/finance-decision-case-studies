## 案例一：并购价值需要与偿债能力一起评估

团队提出 TWE 收购 Australian Vintage 的假设方案，结合高端化与低／无酒精产品能力讨论协同价值。我的分析重点是：增加债务后，公司是否仍有足够的利息支付能力和流动性。

| 核心指标 | 并购前 | 并购后情景 | 分析含义 |
| --- | ---: | ---: | --- |
| 利息保障倍数 | 3.83× | 3.64× | 利息支付缓冲缩小 |
| 速动比率 | 1.07× | 1.01× | 剔除存货后的短期偿债余量减少 |
| 现金比率 | 0.52× | 0.45× | 可用现金缓冲减少 |
| 债务／权益 | 23.69% | 26.27% | 债务融资占比提高 |

*来源：原始 `Project 1.pptx` 第 1 页。并购后数据是课程情景估计，不代表真实交易结果；原始模型底稿不完整。*

**核心判断：**较低的部分杠杆指标可以支持进一步讨论债务融资，但不能单独证明交易可行。利息保障能力与现金缓冲的下降，需要与融资成本、现金流和整合风险同时评估。

## 案例二：把退休策略建立在明确的成员假设上

团队比较生命周期策略与统一平衡型策略。我负责说明两类成员的初始条件，以及缴费率和市场冲击假设如何进入退休情景分析。

| 模型输入 | 新成员 | 50 岁成员 |
| --- | ---: | ---: |
| 起始账户余额 | A$15,480 | A$237,180 |
| 起始年薪 | A$68,470 | A$171,733 |
| 长期缴费率假设 | 12% | 12% |
| 市场下跌情景 | −37% | −37% |

*来源：原始 `Project 2.pptx` 第 1 页。以上为 2023 年课程模型采用的假设，不是当前政策或收益预测。*

**核心判断：**生命周期策略的比较结果取决于成员起点、收入路径、降风险时点和冲击发生阶段。明确这些假设，比单独展示一个退休余额更有解释力。
