## 关键差异及处理

| 问题 | 原始记录 | 处理方式 |
| --- | --- | --- |
| 收购金额与融资比例 | Scope：A$246.82m，60% 债务／40% 现金；讲稿：A$160m，70% 新债／30% 现金 | 同时注明版本，不将不同版本拼接成一套模型 |
| 报价与财务表能否衔接 | 演示第 3 页债务由 1,937.6m 增至 2,174.6m，增加 237m；讲稿 160m × 70% 对应 112m 新融资 | 缺少标的并入债务及其他调整的衔接表，不能确认一致，也不直接认定差额是计算错误 |
| WACC 水平 | 个人报告约 5.54%；演示前后 7.54%／7.53% | 参数方案不同，分别标明，不选取有利数字充当统一结果 |
| WACC 降幅 | 讲稿称下降 0.1%；演示值仅相差 0.01 个百分点，即 1 个基点 | 简历不使用该降幅作为业绩 |
| WACC 算术复核 | 按演示列出的股权成本、债务成本、税率和权重复算：并购前约 7.5576%，后约 7.5300% | 前值与 7.54% 有小幅偏差；未取得未四舍五入输入，保留差异 |
| beta 与股权成本 | 演示前项的 Rf=2.6%、ERP=5%、beta=1.07 可得 Re=7.95%；后项 beta=1.077 得 Re=7.985%，约 7.99% | 该项算术关系可对齐，不证明 beta 选取或全部资本结构假设已验证 |
| 流动性方向 | 讲稿概括流动性下降；演示流动比率 2.04→2.08，速动及现金比率下降 | 分指标解释，避免单一方向概括 |
| 早期流动性报告 | 利息保障倍数 3.26、速动比率 1.03；演示为 3.83、1.07；报告文字对同业强弱也有冲突 | 主表统一采用演示版本，不将报告结论并入 |
| 夏普比率提升 | Brief：0.88→0.92；讲稿：提高 25% | 前者算术相对增幅为约 4.55%，不能据此支持 25%；不作为绩效宣传 |
| 风险收益变化 | Brief 描述预期收益增加 1%、波动增加 0.8%；讲稿描述收益增加 0.8%、风险下降 1.6% | 不合并为统一优化结果 |
| 年龄分段与冲击范围 | Brief 使用 25–50、50–55、55–65、65–67 岁等区间，且冲击作用于 65–67 岁；讲稿使用不同分界并讨论 59 岁以上冲击 | 正文仅展示阶段逻辑，避免制造统一精确年龄表 |

## 资料选择

- 课程题目与中文译本用于理解项目背景，不公开原文。
- `FINC3600 final 2023.pptx` 属于复习材料，不作为个人成果。
- 完整商业数据库导出及原始价格文件未纳入公开仓库；本次案例也不依赖重新发布这些文件。
- 含学号与队友信息的原始文件未复制到公开目录。

## 如何阅读这些差异

版本差异不应被隐藏，也不宜阻止读者理解分析过程。主案例保留可定位的指标摘要，并将未能统一的结果单独说明。这里能展示的是研究、解释与判断能力，以及对证据强度的把握；新增模型提供了可检查的计算逻辑和Excel运行入口；其运行验证和已知问题见[模型检查记录](model-review.md)。
