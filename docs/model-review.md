## 结构与运行入口

- 工作簿包含6张工作表及 `xl/vbaProject.bin`。
- Input 页 Run Simulation 按钮绑定 `GeneratePaths`，该宏读取命名区域中的参数，生成随机路径并写入 Output。
- Analysis 以 AVERAGE、STDEV.S 等公式读取 Output，显示冲击与无冲击统计及图表。
- 未发现外部工作簿链接。该项不等于跨版本兼容性已经验证。

## 已识别的问题

### 1. 随机收益的标准差口径

`GeneratePaths` 使用 `GenerateNormRand(mean, vol * vol)`；被调用函数的第二个参数是 `stdDev`，并直接计算 `mean + stdDev * randStdNormal`。因此，例如输入波动率9.1%时，实际传入的标准差约为0.8281%，而不是9.1%。这会低估收益抽样的波动。

原始宏未修改。正式重算风险前，应由模型维护者确认预期分布，统一标准差口径，并在 Excel 中重新运行全部比较场景。不能沿用原波动结果声称风险显著降低。

### 2. 保存的输入与输出不一致

当前 Input 年龄阶段从25岁开始，Output 保存的年龄标题却从21岁延伸至67岁，说明保存输出不是当前输入状态的可靠对应快照。Analysis 的动态列偏移依赖当前年龄范围，直接重新计算可能指向历史输出的不同年份。

仓库预览仅提取 Output!AW3:AX1002 的终值列。没有把缓存的 Analysis 数字标成当前参数的模拟结果。每次正式演示都应先确认输入、完整运行宏，再读结果。

### 3. 文件与汇报的参数版本不同

- 文件保存的新成员起始工资为74,651，原 Project 2 演示页为68,470。
- 文件年龄区间为25–50、50–55、55–65、65–67；后续讲稿出现不同分界。
- 文件只在第四阶段启用冲击，讲稿另有59岁以上受冲击的方案。

演示指南明确给出所采用的参数，不承诺复现讲稿中的22.06%、69.15%等改善幅度。

### 4. 成员切换会覆盖输入

Input 工作表的 Worksheet_Change 事件在 E15 变化后重置余额和工资，并更新工资公式、隐藏或显示第一阶段。必须先选择成员类型，再填写 E13/E14。

### 5. 冲击开关并非四阶段都生效

GeneratePaths 仅在第3和第4阶段读取 ShockRange 并安排冲击。前两阶段的界面开关不能被当作已实现的冲击能力。

### 6. 运行与模型局限

没有固定随机种子控件；没有完成本次 Excel 运行验收。原宏包含另一个名为 simulate_log_normal 的辅助过程，会写入活动工作表的大量单元格，演示仅使用按钮关联的 GeneratePaths。

原 Return Data 保存的名义均值为 Conservative 6.9%、Balanced 8.4%、Growth 7.8%、High Growth 7.8%；相应波动输入为7.8%、9.1%、7.2%、8.1%。这些是原项目设定，不应自动按名称推断收益排序，也不代表当前市场预测。
