# 分析方法与指标

[返回首页](../README.md)

本页说明原项目涉及的方法，并区分可核算的数据摘要与缺少底稿的完整模型。

## 企业融资

| 方法／指标 | 核心含义 | 使用时需要注意 |
| --- | --- | --- |
| 同业比较 | 判断企业相对融资和偿债情况 | 国家、币种、会计政策及财年差异可能影响可比性 |
| 利息保障倍数 | 常见口径为 EBIT／利息费用 | 需要统一 EBIT 与利息费用定义 |
| 流动比率 | 流动资产／流动负债 | 存货并不等同于即时可用现金 |
| 速动比率 | 速动资产／流动负债 | 需明确是否剔除存货及预付款项 |
| 现金比率 | 现金类资产／流动负债 | 需确认受限现金及可变现资产范围 |
| 债务／权益 | 债务相对权益的规模 | 账面权益与市值权益不可混用 |
| WACC | 股权成本与税后债务成本的加权平均 | 参数、资本权重及风险口径需一致 |

**资本资产定价模型（CAPM）：**股权成本 = 无风险利率 + 股权 beta × 股权风险溢价。

**WACC：**股权成本 × E/(D+E) + 债务成本 × (1−税率) × D/(D+E)。

个人 WACC 报告使用债务账面价值近似债务市场价值，并使用历史利息费用估算债务成本。这些是建模近似，不能直接等同于新增融资的边际成本。

### 本次可核算的内容

- 比率变化采用“并购后 − 并购前”。例如现金比率 0.45 − 0.52 = −0.07。
- 百分比指标的直接相减以“百分点”表达。例如 26.27% − 23.69% = 2.58 个百分点。
- WACC 演示输入的简单算术复核详见证据登记，不等于对原始财务数据及并表模型的全面验证。

## 养老金策略

退休账户积累由期初余额、持续缴费与投资回报共同决定。一个简化的期末缴费表达为：

**下期期初余额 = 本期期初余额 × (1 + 本期收益率) + 本期缴费。**

这仅用于说明变量关系，不声称原项目采用了该时点约定。实际模型还需要说明费用、税收、保险、缴费时点及工资增长等口径。

**夏普比率：**通常用超额收益除以收益波动率衡量风险调整后表现。比较时需保持收益频率、无风险收益与波动率口径一致。

**生命周期策略：**根据成员生命周期调整资产配置。年龄分段与降风险速度会改变退休前后的风险敞口。

**冲击情景：**规定冲击的幅度、发生时点、持续期和作用资产。一个 −37% 输入不能单独定义完整的压力测试。
