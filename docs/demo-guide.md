# 五分钟模型演示

[返回首页](../README.md) · [下载模型](../models/README.md) · [模型检查记录](model-review.md)

## 演示环境

使用支持 VBA 的桌面 Microsoft Excel，下载并打开 `DLIS-Model.xlsm` 的副本，保留 `.xlsm` 格式。仅在确认来源后允许此文件的宏，不需要全局关闭宏安全设置。如组织策略阻止宏，请使用下方静态预览或交由有权限的环境运行。

本步骤根据已检查的单元格和宏编写，尚未在本次环境的桌面 Excel 中执行。模型有已知波动率口径问题，适合讲解原项目流程；不宜据此承诺模拟风险水平已得到正确验证。

## 1. 先介绍决策问题（30 秒）

“我比较统一平衡型与生命周期配置，对新成员和50岁成员分别设定账户及工资条件，在冲击与无冲击情景下观察退休余额分布。”

## 2. 设置成员与参数（约 1 分钟）

进入 Input 页，**先选择 E15 成员类型，再填写 E13 和 E14**。成员切换事件会自动重置余额与工资，倒过来输入会丢失刚填的参数。

以下为根据原项目演示材料整理的演示设定，不是当前打开文件已保存结果的生成参数。

| 输入位置 | 新成员 | 50岁成员 |
| --- | --- | --- |
| E15：成员类型 | New Member | 50-year old |
| E13：起始余额 | 15480 | 237180 |
| E14：起始年薪 | 68470 | 171733 |
| E12：模拟次数 | 1000 | 1000 |
| E16：CPI | 2.5% | 2.5% |
| J6:J9：缴费率 | 各阶段12% | 各阶段12% |

保留此文件的年龄区间：25–50、50–55、55–65、65–67。50岁成员选项会隐藏第一阶段行。I6:I9 的工资增长保留文件值 3.8%、3.8%、2.4%、2.4%。50岁成员的工资从第二阶段起算。

Return Data!F2 的市场冲击设为 −37%。Input!L6:L9 依次为 No、No、No、Yes，表示仅第四阶段启用冲击。**这是原模型文件对应的一种情景，并非最终汇报中59岁以上冲击情景的复现。**

## 3. 比较两种策略（约 2 分钟）

对同一成员分别运行以下设置，除投资选项外保留其他参数：

| 策略 | Input!K6:K9 |
| --- | --- |
| 平衡型基准 | Balanced、Balanced、Balanced、Balanced |
| 生命周期配置 | High Growth、Growth、Balanced、Conservative |

每次操作：

1. 在 Input 页确认成员、余额、工资及四个投资选项。
2. 保持 Excel 自动计算，先完成公式重算。
3. 点击 **Run Simulation**。若按钮无法点击，在 Excel 宏列表选择 **GeneratePaths**；不要运行其他宏。
4. 等待状态栏出现模拟完成信息，再打开 Analysis 页。
5. 记录 D4:E7：冲击与无冲击两列的均值、标准差、最大值和最小值。
6. 将每个场景另存为独立 `.xlsm` 副本，再运行下一组；不要在改动输入后沿用旧结果。

两类成员 × 两种策略 = **4次设置与运行**；每次宏同时输出冲击和无冲击终值，共可比较8组情景结果。模型没有固定种子控件，重新运行可能得到不同样本，不能把微小差异当作确定改进。

## 4. 解释结果（约 1 分钟）

依次回答：退休余额均值如何变化、终值分布有多分散、冲击产生了什么影响、变化是否取决于工资或年龄假设。

原宏将波动率平方后传入标准差参数，会低估随机收益的波动。演示时应明确这是原模型待修正的问题，**不要用原标准差结果证明策略必然更安全**。原 Return Data 中部分高增长策略的预期收益也低于 Balanced，因此不能预设生命周期配置必然获得更高均值。
